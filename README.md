# 面试辅助 v0.2

双声道实时语音转写 + **AI 参考回答**：**面试官**（系统里播放的声音，默认走屏幕采集）与**我**（麦克风）各自独立识别；面试官说完一个问题后，自动结合你的个人档案生成「大纲 + 逐字稿」参考回答（流式显示）。

## 答案层说明

- 首次借用 ScreenRelay 的模型凭据；本应用的候选人档案、目标岗位和模型选择独立保存，不继承另一应用的个人档案。
- 回答格式保持「大纲 + 逐字稿」，支持长短切换。
- 只对需要候选人作答的新问题自动生成；附和、岗位介绍和告别只进入对话记忆。可关闭自动作答，手动点击「就问这个」。
- ASR 全量结果先去掉累计定稿，只传新增句子与未定稿尾句；历史对话与当前问题分别传递。
- 实际发言原文单独保留为证据，摘要仅用于导航；AI 建议不进入候选人的事实记忆。
- 用户已授权合理构造参考情境：有对应材料时优先使用，缺少经历或过程细节时也生成完整可口述的答案，不再因事实核对拒答。已明确的项目分工、更正和数据仍优先保持一致。整体超时为 45 秒。
- 每题使用请求开始时的模型、档案与岗位快照，一次模型调用流式返回大纲与逐字稿。AI编写的情境仅是参考建议，不进入候选人实际发言记忆或自动修改档案。
- 钥匙串读写在独立 Electron 进程中完成，12 秒超时后可在界面重试，不阻塞主窗口；读失败不会清空原档案，加密保存成功后才更新内存并显示保存成功。模型、档案和 JD 的并发修改按序合并。
- 每场目录增加私有 `answer-diagnostics.jsonl`：记录请求快照、来源、参考答案模式及耗时，不写 API 凭据；该文件和本地验证产物不进入转录 HTML 或应用安装包。

## 启动

先安装依赖并创建本机凭据配置：

```bash
npm ci
cp volcano.config.example.json volcano.config.json
```

在 `volcano.config.json` 中填写火山引擎 ASR 凭据，然后双击 `启动.command` 或运行 `npm start`。凭据配置不会提交到 Git。

## 使用前提

**默认音源：屏幕采集（推荐）——不需要 BlackHole、不需要多输出设备、不碰系统输出路由**（音量键照常工作，也不用改腾讯会议之类的应用内扬声器设置）。

只需做一次授权：首次在面试官声道选「屏幕采集」并开始后，到

**系统设置 → 隐私与安全性 → 屏幕与系统音频录制**

给 **SCKCap** 打开开关（系统也可能直接弹窗）。未授权时界面会明确提示你去这里开（日志 `Code=-3801`）。

另外两条运行时前提：

- **屏幕不能休眠/锁屏**——休眠时系统不提供屏幕内容，日志 `NO_DISPLAY`，唤醒后重新开始即可
- 采集的是**整屏全系统混音**，所以任何在响的声音（会议/视频/音乐）都会被收进来

**备选音源：BlackHole**（虚拟声卡，需要装 BlackHole 2ch，并在「音频 MIDI 设置」创建「多输出设备」设为默认输出）。注意 macOS 15 **不允许程序把聚合设备设为默认输出**（实测 set 返回成功但读回不变），所以这一步必须手动：应用检测到不对会显示「声音设置 / 音频 MIDI 设置」按钮引导你。多输出设备也不支持统一音量（音量键失效），识别期间如需调音量请调播放源自带音量。

屏幕采集的音频链路：`native/sckcap.app`（ScreenCaptureKit 整屏捕获 → 转 16kHz/单声道/Int16 → stdout）→ 主进程按 200ms 切片送 ASR。

## 界面说明

- 每个声道一个卡片，点「开始」即开始实时转写，再点「停止」结束
- 灰色字 = 实时中间结果（会变），黑色行 = 已定稿句子（带时间戳）
- 状态点：灰=未开始，绿=识别中，黄=重连中，红=出错
- 识别服务：火山引擎豆包流式语音识别（凭据在本机的 `volcano.config.json`；该文件已加入 Git 忽略列表）

## 验证

运行 `npm test` 检查问题识别、ASR 累计文本处理、原文证据、材料不足时正常作答、流式输出及主进程发布/取消行为。

`scripts/replay-real-interview.cjs` 使用本地原始 `transcript.jsonl` 在真实渲染器中按虚拟时钟回放，接口桩不调用模型或采集音频。`scripts/verify-reference-answer.cjs` 是显式执行的在线验证脚本，会读取本应用加密配置并调用当前模型，结果只写入本地 `artifacts/`。

## 已知限制

- 开发启动依赖启动脚本指定的本地 Electron 运行时。
- 未做超过 30 分钟的音频与网络长稳测试。
- 参考答案允许构造情境，不能当作已核验的个人事实。
